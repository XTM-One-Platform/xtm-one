# Final-stage runtime packages for sandbox-python-data
# (the apt.sandbox.extended.txt family that stays on the Debian-slim
# "final-full" target — see research.md §2/§3). Only the *-dev headers and
# compilers from apt.sandbox.extended.txt are dropped from this list; these
# are the actual shared libraries the installed wheels dlopen at import time.
#
# sandbox-python-malware and sandbox-python-network each need this same
# shared-library block plus their own tag-specific additions (DFIR libs,
# tshark/nmap/libkrb5) — there's no build step that composes multiple apt
# files, so apt.sandbox.malware.runtime.txt and apt.sandbox.network.runtime.txt
# each carry a full hand-kept-in-sync copy of this block rather than a diff.
#

libgomp1

libgeos-c1t64
