# Extended sandbox requirements — reference catalog (NOT a single installable environment).
#
# ⚠ These 200+ packages span multiple tool families with conflicting transitive
#   dependencies (click, requests, pandas version constraints clash across security
#   tools). They CANNOT all be installed in one environment.
#
# Use the per-domain split files instead:
#   requirements.sandbox.cti.txt     — CTI, IOC enrichment, SIEM, rules engineering
#   requirements.sandbox.network.txt — Network automation, PCAP, protocols, identity
#   requirements.sandbox.malware.txt — Malware analysis, reverse engineering, DFIR
#   requirements.sandbox.soar.txt    — SOAR, cloud security, supply chain, email, automation
#   requirements.sandbox.data.txt    — Data science, ML, NLP, visualization, document I/O
#
# This file is kept as a searchable reference for the full package catalog with
# purposes, removal notes, and version history.
#
# NOTE: several packages require OS-level build deps not in the base sandbox image
# (libmagic, libfuzzy, libgcrypt, libpcap, libssl, libgdal …).
# See apt.sandbox.extended.txt for the full OS dependency list.
