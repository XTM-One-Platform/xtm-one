## Rules

- **Credentials only in the DB**, Fernet-encrypted per integration, set in the UI, never env vars.
- **An OAuth token is personal**: who may use it: `services/integration_credentials.py` (`oauth_credentials_usable[_clause]()`, `require_oauth_credentials_usable()`); consent is written only by `apply_oauth_share_consent()`. A new read of a token column fails `test_integration_credential_gate.py` until listed there.
- **Bound credentials are used as bound** through `build_integration_tools()`, except `credential_mode = per_user`: every reader resolves it via `services/integration_user_credentials.resolve_token_holder()`, never the holder's token for someone else.
- **A credential refusal is never silent**: the 403 says how the token gets shared; a chat turn tells model and user.
- **HTTP through `http.py`**: `safe_request` / `format_http_error` / `format_network_error`, never `raise_for_status()` or inline handling; `parse_compound_token` for `||` tokens (`greedy_last=True` when the last field is a secret).
- **Retry transient 5xx only on idempotent calls** (`retry_statuses=TRANSIENT_RETRY_STATUSES`), never a write.
- **Failures read as failures**: a provider helper starts every failure with `Error: `, a refusal is `ToolResult(is_error=True)`; never widen `is_error_shaped_result` to catch a provider's wording.
- **One User-Agent**: send `PLATFORM_USER_AGENT`, never spell it out (`test_platform_user_agent.py`).
- **Shared caches and limiters**: app tokens via `get_cached_app_token`, OAuth2 grants via `oauth_token_grants.get_grant_token`, rate caps via `get_shared_rate_limiter` keyed on `app_token_cache_key()`, short-lived JWTs via `RefreshableHeaders` + `ensure_fresh_token`.
- **Files**: a file tool gives links, a download, `ToolResult.files` and a `file_id` pipe; build with `deliver_file()`, read uploads with `read_pipe_file()`, never re-spell either.
- **`fetch_file` is the ONE download helper**: no second streaming loop, no httpx `follow_redirects` while a non-`Authorization` credential rides the request.
- **A token goes only to the provider's own host**; a signed or API-handed URL is fetched without it through `social_media.fetch_public_media` (outbound URL policy on every hop).
- **A provider reading `persist_file_fn`** is in `integration_tools._PERSIST_FILE_PROVIDERS` / `_PERSIST_FILE_CHANNEL_BOTS` (`test_tool_result_files.py`).
- **Possible malware**: `deliver_live_artefact()` (sealed `infected` ZIP only, never on `ToolResult.files`), else `live_artefact_links()`.
- **`wrap_untrusted`** wraps vendor-shaped text only in `supabase`, `crowdstrike_ngsiem`, `xtm_hub`, `opencrq` (`_common._quarantined`) and `untrusted_response` bundle tools, and a file's facts only via `untrusted_file_facts`, never in an answer's open text or error; `notes=` holds only the platform's lines. Uploads name the file by `file_id`, then `uploaded_file_answer`.
- **Stale references**: report only a sustained miss on a resource the run addressed (`report_stale_reference()`, withdrawn by `confirm_reference_alive()`), never a first miss or an id only read; the tool result stays unchanged.
- **Every user-supplied URL** (OpenAPI spec, refs, discovery, tool calls, OAuth) passes `app.core.destination_policy`, connections pinned, never a second address list.
- **OpenAPI**: one provider key `openapi`, tool scopes per instance (`openapi@<id>`), tool names max 48 chars, the credential only on the base URL's origin and never in a transport header, imported `pattern`s never enforced, a refresh never widens the surface.
- **Declarative handlers** only come from `make_declarative_handler()`; a bundle constant is never read from the arguments.
- **`get_integration_public_url()`** surfaces a base URL only for `_USER_FACING_BASE_URL_PROVIDERS`, listed only when it is the web UI host.
- **OpenCRQ**: procedures named by literals, never built at runtime (`test_opencrq_trpc_contract.py`); tool maps generated by `scripts.dump_opencrq_tool_procedures`, never hand-edited.
- **Lifecycle hooks** (`register_lifecycle`): `on_connect` / `on_disconnect` are best-effort and never raise; an `on_update` failure fails the edit.

## Adding a new integration

1. Create `providers/<name>.py` whose `build_tools(token, executor, **kwargs)` goes in `PROVIDER_TOOLS`, or a package split by domain like `opencti/`; share one header builder / base-URL function with the connectivity test.
2. Add the entry to `PROVIDER_CATALOG` (`api/v1/integration_catalog.py`) with an `integration_category` from the taxonomy; a new category also updates `INTEGRATION_CATEGORY_*` in `frontend/src/lib/constants.ts`.
3. Test Connection: an authenticated call in the `checks` table of `api/v1/integration_testing.py`; health kept in our own state registers a probe (`connectivity.register_connectivity`), never an `elif`. A probe is read-only and cheap, never echoes a credential, never raises, and quotes a stored error only when `ctx.caller_can_manage`.
4. Add its row to the provider reference doc.
