## Install

Double-click `xtm-one-platform.mcpb`, or drag it into the Claude Desktop
window, or go to **Settings → Extensions → Advanced settings → Install
Extension…**.

Claude Desktop asks for your API key during installation and keeps it in its
own secure storage — it is not part of this file.

Create the key in **My Profile > API Keys** on {{PLATFORM_NAME}}. Use a
dedicated key for this client so you can revoke it on its own.
