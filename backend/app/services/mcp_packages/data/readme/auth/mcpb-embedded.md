## Install

Double-click `xtm-one-platform.mcpb`, or drag it into the Claude Desktop
window, or go to **Settings → Extensions → Advanced settings → Install
Extension…**.

Nothing is asked of you: the endpoint URL and an API key are already in the
bundle.

## This file is a credential

The bundle was generated with a **new API key** created for it, named
`{{KEY_NAME}}`, written into `manifest.json`. Treat the file like the key it
contains:

- do not commit it, share it, or attach it to a ticket;
- delete it once installed — Claude Desktop has stored what it needs;
- revoke the key in **My Profile > API Keys** if the file goes anywhere it
  should not have. It is a key of its own, so revoking it breaks nothing else.

Prefer to be asked for the key at install time? Download the bundle again
without the key, from **My Profile > MCP Endpoint**.
