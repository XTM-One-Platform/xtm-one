# Foundations

This section introduces the concepts behind the product before the rest of the guide walks through individual screens. It is most useful when you are new to XTM One, when the object names still feel abstract, or when you are moving between XTM One and other Filigran products.

The pages cover:

- [`Data model`](data-model.md) — the main platform objects.
- [`Relationships and nesting`](relationships-and-nesting.md) — how one object references another.
- [`Containers and scopes`](containers-and-scopes.md) — how work is grouped and where visibility applies.
- [`Reuse and deduplication`](deduplication.md) — when to reuse a shared object and when to create a copy.
- [`Trust, review, and confidence`](trust-and-confidence.md) — how to judge AI outputs operationally.
- [`Meaning of dates and status`](dates-and-status.md) — the timestamps and status labels you see across the product.
